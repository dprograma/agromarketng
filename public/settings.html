📄 .env Reference

Copy .env.example → .env and fill in values. Restart server after changes.

APP_PORT=3000
APP_URL=http://localhost:3000
APP_SECRET=your_jwt_secret_here

# Groq AI — FREE tier (https://console.groq.com)
GROQ_API_KEY=gsk_...

# Images (pick one or both)
UNSPLASH_ACCESS_KEY=...   # https://unsplash.com/developers (free)
PEXELS_API_KEY=...        # https://www.pexels.com/api/   (free)

# Email (Gmail: use App Password, not your real password)
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=you@gmail.com
SMTP_PASS=xxxx-xxxx-xxxx-xxxx
APPROVAL_EMAIL=where_to_send@example.com

# Facebook / Instagram (https://developers.facebook.com)
FACEBOOK_PAGE_ID=123456789
FACEBOOK_PAGE_ACCESS_TOKEN=EAAxxxxxx
INSTAGRAM_ACCOUNT_ID=17841xxxxx

# Twitter/X (https://developer.twitter.com)
TWITTER_API_KEY=...
TWITTER_API_SECRET=...
TWITTER_ACCESS_TOKEN=...
TWITTER_ACCESS_SECRET=...

# LinkedIn (https://www.linkedin.com/developers)
LINKEDIN_ACCESS_TOKEN=AQV...
LINKEDIN_PERSON_URN=urn:li:person:xxx
# For company page: LINKEDIN_ORG_URN=urn:li:organization:xxx

# TikTok (https://developers.tiktok.com)
TIKTOK_ACCESS_TOKEN=act...
TIKTOK_OPEN_ID=...

# Site info (can also be set from the UI above)
